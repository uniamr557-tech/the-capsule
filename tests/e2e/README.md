# End-to-End Testing (Playwright)

This directory contains end-to-end browser tests for **The Capsule**.

- `join.spec.ts`: Senior access code entry, validation, error neutrality, and session creation.
- `contribute.spec.ts`: Direct photo/video upload, memory submission, and confirmation.
- `moderate.spec.ts`: Senior Admin Content Manager actions (hide, restore, permanent delete).
- `archive.spec.ts`: Read-only archive freeze behavior.
