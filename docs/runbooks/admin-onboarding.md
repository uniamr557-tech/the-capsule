# Senior Admin Onboarding Checklist

Welcome to **The Capsule**! This guide assists Senior Admins ("Class Presidents / Curation Leads") in setting up and operating their class capsule.

---

## 📋 Setup Checklist (Under 10 Minutes)

1. **Receive Recovery Secret:**
   - Upon purchase/fulfillment, save your One-Time Emergency Recovery Secret in a password manager.
2. **Access Admin Studio:**
   - Open your passwordless login link delivered via email or sign in using your recovery secret at `/admin/login`.
3. **Configure Capsule Details (`Appearance Studio`):**
   - Verify school name, class title (*Class of 2026*), and graduation year.
   - Select your class accent theme (*Marigold*, *Lake Blue*, *Lilac*, *Poppy*, or *Evergreen*).
   - Enter your welcome message (e.g., *"A place for the moments you will want to remember forever"*).
4. **Generate Initial Class Access Code (`Access Code Studio`):**
   - Click **Generate Initial Code** to create your 8-character class access code (e.g. `SENIOR26`).
   - Copy the share card for distribution to your classmates.

---

## 🛡️ Operational Best Practices

- **Code Rotation:** Rotate the class code whenever you suspect it has been shared outside your senior class. Existing active sessions will be cleanly revoked.
- **Content Moderation:** Use the **Content Manager** to review uploads. Soft-hiding an item removes it instantly from classmate views without deleting it permanently.
- **Graduation Archive:** Once graduation week concludes, navigate to **Archive Controls** and freeze the capsule to read-only state.
