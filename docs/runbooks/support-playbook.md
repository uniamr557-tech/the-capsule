# Support Playbook & Escalation Procedures

---

## 1. Common Support Inquiries

### Issue 1: "Seniors cannot log in / Code isn't working"
- **Diagnosis:** Code has been rotated or session cookie expired.
- **Resolution:** Senior Admin opens Admin Studio $\rightarrow$ Access Code Studio, unmasks current active code, and distributes to class.

### Issue 2: "Inappropriate photo posted"
- **Diagnosis:** Content requires moderation.
- **Resolution:** Senior Admin opens Admin Studio $\rightarrow$ Content Manager, filters by `visible`, locates item, and clicks **Hide**. Item disappears instantly.

### Issue 3: "Admin lost access key"
- **Diagnosis:** Admin changed mobile devices or cleared cookies.
- **Resolution:** Admin uses One-Time Emergency Recovery Secret at `/admin/login`.
