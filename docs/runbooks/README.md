# Operational Runbooks

This directory contains procedures for emergency operations, data retention purges, and disaster recovery.

- `emergency-code-rotation.md`: Procedures for revoking compromised access codes manually.
- `database-pitr-restore.md`: Database Point-In-Time Restore steps.
- `media-purge-verification.md`: Verifying permanent deletion of soft-deleted media assets from S3 buckets.
