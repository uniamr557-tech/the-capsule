# Release Notes — Version 1.0.0

**The Capsule v1.0.0** is the official production release of the private digital yearbook and memory capsule web application for graduating high school classes.

---

## 🌟 Highlights of v1.0.0

- **Intimate & Accountless Senior Experience:** Graduating seniors join using a shared 8-character class access code without creating accounts or passwords.
- **Editorial Archive Aesthetics:** Warm paper canvas (`#F7F4EE`), rich ink (`#1D1C1A`), curated theme accents, `DM Serif Display` typography, and zero dopamine/feed noise.
- **Direct-to-Storage Media Uploads:** Resilient direct S3 uploads with automatic EXIF metadata sanitization and responsive WebP/AVIF variants.
- **Senior Admin Studio:** Operational console for rapid content moderation, atomic code rotation, branding customization, and archival read-only freeze.
- **Production-Grade Security & Performance:** 13-table PostgreSQL schema, salted HMAC hashes at rest, CSP middleware, 99.9% availability SLO, and sub-400ms API response latency.
